# Data

This directory is reserved for reproducible experimental data.

## Provenance requirements

Every dataset should include:

- source;
- date/time;
- instrument or simulator version;
- units;
- calibration state;
- environmental conditions;
- processing steps;
- checksum where practical.

Raw measurements should be preserved separately from derived data.

Synthetic or simulated datasets must be clearly labeled as such and must never be presented as hardware measurements.
