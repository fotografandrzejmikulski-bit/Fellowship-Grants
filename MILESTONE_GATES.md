# Technical Milestone Gates

## G1 — Numerical integrity
Deterministic runs reproduce within declared tolerances; units and seeds are explicit.

## G2 — Nonlinear-device model
A candidate nonlinear element has parameter provenance, a thermal/dynamic model, sensitivity analysis and a documented operating envelope.

## G3 — System co-design
Latency and energy include relevant source, modulation, propagation, conversion, control, memory and calibration terms.

## G4 — Physical prototype
Measured traces, raw-data hashes, instrument metadata and environmental conditions are archived.

## G5 — End-to-end edge demonstration
The predeclared workload meets the application accuracy requirement while reporting measured latency and energy against a reproducible electronic baseline.
