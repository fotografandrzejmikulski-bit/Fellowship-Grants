# Evidence Levels

LuminaCore uses a strict evidence hierarchy:

| Level | Definition | Allowed claim |
|---|---|---|
| E0 | Hypothesis / proposal | Research objective only |
| E1 | Analytical estimate | Model-derived expectation |
| E2 | Simulation or executable system model | Model result, never hardware result |
| E3 | Physical measurement | Experimental device/system result |
| E4 | Independent replication / external validation | Independently corroborated result |

A quantitative headline may advance only when the underlying evidence level advances. Repository code does not itself constitute experimental evidence.
